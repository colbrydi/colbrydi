# Dr. Dirk Colbry

I work at Michigan State University at the intersection of computational science, research software, education, and automation. This GitHub profile contains projects, resources, and tools developed to support students, researchers, instructors, and community partners. For more information about me, please see my [personal website](http://www.dirk.colbry.com/).
